# 4-Bit-Counter-using-Verilog
A Verilog HDL based 4-Bit Counter project designed to perform sequential counting operations using digital logic and flip-flop concepts.

## Overview
The 4-Bit Counter is a digital design project implemented using Verilog HDL. The counter increments binary values sequentially based on clock pulses and demonstrates the working of sequential circuits in digital electronics.

This project helps in understanding counter design, flip-flops, and RTL concepts using Verilog.

## Features
- 4-Bit Binary Counting
- Sequential Circuit Design
- Clock Pulse Based Operation
- Verilog HDL Implementation
- Efficient Counter Logic
- Digital Timing Control

## Technologies Used
- Verilog HDL
- Digital Electronics
- Sequential Circuit Design
- RTL Design
- Xilinx Vivado 

## Software Requirements
- Xilinx Vivado
- Verilog Simulator

## Working Principle
The 4-Bit Counter changes its binary output sequentially with every clock pulse. The counter counts from 0000 to 1111 and then resets back to 0000 automatically.
